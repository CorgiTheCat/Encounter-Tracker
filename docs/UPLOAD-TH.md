# วิธีนำชุดนี้ขึ้น GitHub

ชุดนี้เป็น **ซอร์สโค้ด** ไม่ใช่ ZIP สำหรับลากลง Netlify โดยตรง

1. แตก ZIP นี้ก่อน
2. สร้าง Repository ว่างใน GitHub เช่น `encounter-tracker` เลือก Private ถ้ายังไม่ต้องการเปิดโค้ดสาธารณะ
3. อัปโหลดไฟล์และโฟลเดอร์ข้างใน โดยให้ `README.md`, `package.json`, `netlify.toml`, `src` และ `public` อยู่บนสุด ไม่ซ้อนในโฟลเดอร์อีกชั้น
4. อย่าลืมไฟล์ `.gitignore` และ `.gitattributes` หากเครื่องซ่อนไฟล์เหล่านี้ไว้
5. ตรวจรายการไฟล์ก่อน Commit ไม่ใส่ ZIP รุ่นเก่า, `node_modules`, `dist`, รหัสผ่าน หรือข้อมูลห้องเกม
6. เชื่อม Repository นี้กับโปรเจกต์ Netlify ที่ต้องการใช้ ค่า build คือ `npm run build` และ publish คือ `dist` มีตั้งไว้ใน `netlify.toml` แล้ว
7. เมื่อ Published แล้ว ทดสอบ `/manifest.json` และเปิด Extension ใน Owlbear

หากต้องการใช้การลากไฟล์ลง Netlify แบบเดิม ให้เปิด Terminal ในโฟลเดอร์นี้ รัน `npm run build` แล้วอัปโหลดโฟลเดอร์ `dist` แทน

ยังไม่ได้เลือกไลเซนส์โอเพนซอร์สให้โค้ดหรือโลโก้ ควรตัดสินใจเรื่องสิทธิ์ก่อนอนุญาตให้ผู้อื่นนำไปใช้ต่อ

ชุดนี้ไม่มีประวัติ Git ไม่มี remote และยังไม่ได้สร้างหรืออัปโหลด Repository ให้
